# Audio credits

All audio here is **CC0 1.0** (public domain — no attribution required, but
appreciated). The source files are not bundled; only the tracks the game uses
are kept, renamed to their role.

## Music — `music/`

**"Mirrorshade"** by James Gargette — short dub-techno loops for cyberpunk
ambience, CC0. https://opengameart.org/content/mirrorshade

- `menu.mp3` · `campaign.mp3` · `adventure.mp3` · `victory.mp3`

Looping is set in code (`Audio`), not in the files.

## Sound effects — `sfx/`

**Kenney — Interface Sounds** (kenney.nl), CC0.
https://opengameart.org/content/interface-sounds

Each file is one Kenney sound renamed to the event it plays on: `navigate`,
`select`, `back`, `submit`, `error`, `success`, `hint`, `rankup`,
`achievement`, `orb`, `jump`, `setback`, `portal`.
