# Art credits

All pixel-art tiles in this folder are from **Kenney** (https://kenney.nl),
released under **CC0 1.0** (public domain — no attribution required, but very
much appreciated).

- **Kenney — Tiny Dungeon**: characters, monsters, consoles, floor.
  (player, tux, archivist, gatekeeper, miner, console, console_done, floor, floor_alt)
- **Kenney — Tiny Town**: walls, door, key icon, and the boss "robot".
  (wall, door, key, boss)

See `LICENSE_tiny-dungeon.txt` and `LICENSE_tiny-town.txt`.

Downloaded from kenney.nl; only the individual tiles used by the game were
kept. To swap the art, drop replacement 16×16 PNGs with the same names here —
`scripts/world2d/sprite_factory.gd` loads them by name.
